# Selected work

These projects show how I move between method development, evaluation and usable software. My current enterprise work is not public, so the open-source projects below provide the clearest inspectable examples of my technical approach.

<div class="project-grid project-grid-wide">
  <article class="project-card">
    <span class="card-label">Explainable AI · Python package</span>
    <h2><a href="https://github.com/klestdedja/bellatrex">Bellatrex</a></h2>
    <p>Explains individual Random Forest predictions using a small, diverse set of representative rules. The method supports classification, regression, multi-label, multi-target and survival settings.</p>
    <p><a href="https://pypi.org/project/bellatrex/">Package on PyPI →</a></p>
  </article>
  <article class="project-card">
    <span class="card-label">Survival analysis · Feature attribution</span>
    <h2><a href="https://github.com/klestdedja/intervalSHAP">IntervalSHAP</a></h2>
    <p>Extends SHAP-style explanations to time-to-event predictions, focusing on feature importance over selected time intervals.</p>
  </article>
  <article class="project-card">
    <span class="card-label">Active learning · Reproducibility</span>
    <h2><a href="https://github.com/KlestDedja/AL-SA-paper-material">Active Learning for Survival Analysis</a></h2>
    <p>Code and experimental material for active-learning strategies with censored outcomes and incrementally disclosed labels.</p>
  </article>
  <article class="project-card">
    <span class="card-label">Computer vision · Biomedical imaging</span>
    <h2><a href="https://github.com/klestdedja/directionality">EDGEHOG</a></h2>
    <p>A workflow based on Histograms of Oriented Gradients for measuring fibre alignment and directionality dispersion in biological images.</p>
  </article>
</div>

At **CGI SmartLab**, I work on an enterprise RAG application and contribute to prompt behaviour, retrieval, automated LLM evaluation and front-end functionality. At **Predikt.ai**, I worked on time-series forecasting, model validation and uncertainty estimation for finance use cases. These projects are described at a non-confidential level on the [homepage](/) and in my [public CV](/cv).
